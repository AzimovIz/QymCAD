# Сплайн

Клавиша **N**. Гладкая кривая по точкам.

![Сплайн по четырём точкам: гладкая кривая, проходящая через них.](img/sketch-spline.png)

## Как нарисовать

Нажмите **Сплайн** и щёлкайте узлы по порядку; **двойной щелчок** ставит последний и заканчивает кривую. Узлы
потом можно тянуть мышью — кривая пойдёт за ними.

## Осторожно с определённостью

У каждого узла две степени свободы, и определить сплайн целиком размерами почти невозможно. Это нормально для
художественной формы и плохо для ответственного контура: где форму задаёт функция (обвод, аэродинамика,
эргономика), сплайн уместен; где размер (посадка, отверстие, стык) — лучше линии и дуги.

## Если не вышло

Контур из сплайна не выдавливается — концы сплайна не сходятся с соседями. Прибейте их связью **Совпадение** к
концам соседних линий.
